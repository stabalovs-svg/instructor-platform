# Виджет инструкторов IKARS для сайта автошколы

Этот код показывает только публичных инструкторов выбранной автошколы. Личный кабинет, ученики, платежи и другие закрытые данные в виджет не передаются.

В шапке виджета автоматически показывается название автошколы и, если он загружен в настройках школы, её логотип. Небольшая подпись IKARS находится внизу и не конкурирует с брендом партнёра.

Для партнёрской автошколы со slug `partneru-autoskola` вставьте в HTML страницы:

```html
<iframe
  src="https://ikars-instructor-platform.vercel.app/#widget/partneru-autoskola/full"
  title="Braukšanas instruktori"
  loading="lazy"
  style="width:100%;min-height:1000px;border:0;border-radius:16px;"
  allow="clipboard-write"
></iframe>
```

Минимальный вариант Banner для сайта, где уже есть собственный список инструкторов:

```html
<iframe
  src="https://ikars-instructor-platform.vercel.app/#widget/partneru-autoskola/banner"
  title="Braukšanas instruktori"
  loading="lazy"
  style="width:100%;min-height:260px;border:0;border-radius:12px;"
></iframe>
```

Banner показывает преимущества и одну кнопку перехода в публичный каталог. Compact — рекомендуемый встроенный список. Full — полная замена раздела инструкторов.

При подключении другой автошколы меняется только значение после `#widget/`. Его выдаёт администратор IKARS. Короткий адрес с `#widget/` выбран специально: он надёжнее открывается из мобильных приложений и мессенджеров, которые иногда удаляют параметры после `?`.

Компактный вариант для сайта, на котором уже есть собственный большой список инструкторов:

```html
<iframe
  src="https://ikars-instructor-platform.vercel.app/#widget/partneru-autoskola/compact"
  title="Braukšanas instruktori"
  loading="lazy"
  style="width:100%;min-height:700px;border:0;border-radius:12px;"
></iframe>
```

Перед публикацией нужно проверить на компьютере и мобильном телефоне:

1. отображаются только инструкторы этой автошколы;
2. работают фильтры, телефон и календарь свободного времени;
3. высоты 1000 px достаточно для страницы партнёра;
4. статистика открытия, просмотра профиля и клика по телефону поступает в кабинет автошколы.

## Что передать разработчику сайта

- готовый код `iframe` из этой инструкции;
- slug автошколы;
- желаемое место виджета на странице;
- просьбу проверить ширину на телефоне и не ограничивать `iframe` фиксированной шириной;
- контакт IKARS на случай технического вопроса.
